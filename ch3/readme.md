# Chapter 3: Hands-on with Apache Iceberg

## What this chapter covers

* Setting up an Apache Iceberg environment   
* Creating Iceberg tables in Spark   
* Reading Iceberg tables in Dremio  
* Building a business intelligence (BI) dashboard

We’ve explored key ideas behind the Apache Iceberg lakehouse, including its architecture, components, and trade-offs. This chapter moves from theory to hands-on work. The goal isn’t just to build something that works, but to *feel* how a lakehouse comes together end to end, so that as we examine each component later in the book, you’ll have a concrete picture of how the pieces fit together.
